# Инструкция по созданию шаблона договора аренды (LeaseTemplate.docx)

## Обзор
Приложение теперь поддерживает автоматическое заполнение договора аренды в формате Word (.docx) на основе введенных данных.

## Как создать шаблон LeaseTemplate.docx

### Шаг 1: Создайте документ Word
1. Откройте Microsoft Word
2. Создайте новый документ с текстом вашего типового договора аренды

### Шаг 2: Добавьте закладки (Bookmarks) для подстановки данных
В вашем шаблоне должны быть следующие закладки (имена чувствительны к регистру):

| Имя закладки | Описание | Пример значения |
|-------------|----------|-----------------|
| `LeaseNumber` | Номер договора | "123/2024" |
| `LeaseDate` | Дата заключения договора | "15.01.2024" |
| `StartDate` | Дата начала аренды | "01.02.2024" |
| `EndDate` | Дата окончания аренды | "31.01.2025" |
| `MonthlyAmount` | Ежемесячная плата | "50 000,00" |
| `TenantName` | ФИО/Название арендатора | "Иванов Иван Иванович" |
| `TenantINN` | ИНН арендатора | "123456789012" |
| `TenantPhone` | Телефон арендатора | "+7 (999) 123-45-67" |
| `TenantEmail` | Email арендатора | "tenant@example.com" |
| `PropertyAddress` | Адрес объекта | "г. Москва, ул. Ленина, д. 1" |
| `PropertyArea` | Площадь объекта | "50.00" |
| `PropertyType` | Тип объекта | "Офисное помещение" |
| `MonthlyRent` | Стоимость аренды по объекту | "50 000,00" |

### Шаг 3: Как добавить закладку в Word
1. Выделите место в документе, куда нужно подставлять данные
2. Перейдите на вкладку **Вставка** → **Закладка** (или **Insert** → **Bookmark**)
3. Введите имя закладки (например, `TenantName`)
4. Нажмите **Добавить** (Add)

### Шаг 4: Сохраните шаблон
Сохраните файл как `LeaseTemplate.docx` и поместите его в папку:
```
<Папка_приложения>\Resources\LeaseTemplate.docx
```

При публикации приложения убедитесь, что файл копируется в выходную директорию.

## Как это работает

1. Пользователь нажимает кнопку **"Добавить договор"** в разделе "Объекты недвижимости"
2. Открывается форма заполнения договора
3. Пользователь вводит все необходимые данные
4. При нажатии **"Сохранить и создать договор"**:
   - Данные сохраняются в базу данных
   - Копируется шаблон LeaseTemplate.docx
   - Закладки в документе заполняются данными из формы
   - Готовый документ сохраняется в "Мои документы\Договоры аренды\"
   - Путь к файлу сохраняется в базе данных
   - Пользователю предлагается открыть созданный документ

## Требования

- **Microsoft Word** должен быть установлен на компьютере пользователя для автоматического заполнения документа
- Шаблон `LeaseTemplate.docx` должен находиться в папке `Resources`

## Альтернативный вариант (без Microsoft Word)

Если Microsoft Word не установлен, можно использовать библиотеку **OpenXML SDK** или **DocX** для манипуляции .docx файлами без установки Office.

Для этого потребуется:
1. Установить NuGet пакет: `Install-Package DocumentFormat.OpenXml`
2. Переписать метод `FillWordDocument` для работы с OpenXML

## Пример текста договора с закладками

```
ДОГОВОР АРЕНДЫ НЕДВИЖИМОСТИ № {LeaseNumber}

г. _____________                                    «{LeaseDate}» г.

Арендодатель и Арендатор заключили настоящий договор о нижеследующем:

1. ПРЕДМЕТ ДОГОВОРА
1.1. Арендодатель передает Арендатору во временное владение и пользование следующее имущество:
    Адрес: {PropertyAddress}
    Площадь: {PropertyArea} кв.м.
    Тип: {PropertyType}

2. СТОИМОСТЬ И ПОРЯДОК ОПЛАТЫ
2.1. Ежемесячная арендная плата составляет: {MonthlyAmount} рублей.
2.2. Арендная плата вносится ежемесячно до 10 числа текущего месяца.

3. СРОК ДЕЙСТВИЯ ДОГОВОРА
3.1. Договор действует с {StartDate} по {EndDate}.

4. АРЕНДАТОР
Наименование: {TenantName}
ИНН: {TenantINN}
Телефон: {TenantPhone}
Email: {TenantEmail}

5. ПОДПИСИ СТОРОН

Арендодатель: ___________________    Арендатор: ___________________
```
